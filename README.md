# Bangcaya Dashboard

My portfolio site — a dashboard-style single page you flip between 6
sections: Home, Projects, Skills, Credentials, About, Contact.

## Files

- `index.html` — content/structure for every page
- `styles.css` — colors, spacing, dark mode, mobile layout
- `script.js` — page switching, dark/light toggle, the tools ticker
- `images/` — profile photo, project pic, cert scans
- `certs/` — original cert files for the couple credentials without an online verify link

## Viewing it

Just open `index.html` in a browser, no build step or anything. Keep
the whole `bangcaya-dashboard` folder together since everything links
with relative paths.

## Making changes

- Text, new project, new cert -> `index.html`
- Colors/spacing/fonts -> `styles.css`
- Click behavior -> `script.js`
- New picture -> drop it in `images/`, reference it like the others
